How does this work? Just press a website, it'll open it for you, then you'll be able to check for the keys yourself. Also, this website will keep track of what websites (and which pages) you have checked. All it takes to reset this is to press this button:

 

Show clickspot locations

Highlights every clickspot in red with blue background. Every image that can be clicked will be highlighted in blue.
 

Show file locations

There are 2 types of click spots: spots for files, and spots for keys. This will show file locations
 

Show key locations

There are 2 types of click spots: spots for files, and spots for keys. This will show key locations
 

Show key text locations

Basically, there are specific spots that keys can spawn in the website. Selecting this option will have all of those spots have a fake key in them to simulate this. That way, you know where to look when using the website
 

Rainbow text location

Sometimes its hard to see the key text inside the website. This will make them rainbow. Hovering over them will make them their default color.
 

Show text keys only on hover

Shows a green box where a text key is. If you want to see it, you have to hover over the green box. Clicking it locks the key in place and hides the box. Clicking the key makes the green box appear and the key get removed from the text
 

Show text area

Sometimes in websites, I need to add things like notes, options, or other things. If you want those to appear, select this, and check out the options for what to have inside it.
 

Include notes

Sometimes I need to add notes to websites about the visibility of certain clickspots. This shows you those notes. You can turn them off if you don't care
 

Show website pages

This will add a list of all the pages for a specific website. Clicking on the pages will take you to them. Makes navigation easier
 

Show clickspot amount

This shows how many clickspots there are. Useful if you want to check to see if there are any sneaky hidden ones you didn't see. Keep in mind hidden clickspots usually have a note attached to them, so you might want to enable "Include notes" if you are worried about them
 

Show clickspot type toggles

This allows you to toggle showing file and key clickspots. Useful if you only want a website for keys and/or files, or if you want to check for one or the other first
